# Supplementary repository for the contribution  "On the controller form for linear hyperbolic MIMO systems with dynamic boundary conditions" 

Contributed to the 24th European Control Conference

## Structure

Inside the IPython notebook `hansen_zuazua.ipynb` you may find the computation of the hyperbolic mimo controller form for the example discussed in the paper

## Usage

To run the notebook, install the `uv` package manager (https://docs.astral.sh/uv/getting-started/installation/) an run
the command

```
$ uv run jupyter lab
```

to start a jupyter instance which should automatically open a new browser window in which you can then open the notebook.
